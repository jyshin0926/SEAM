# SEAM

Listening demo for **SEAM** (speech-conditioned affective music generation).

**Site:** https://jyshin0926.github.io/SEAM/

Task 1 — emotion alignment on IEMOCAP Session 5.

Each set: speech, then SA3 lexical, SA3 VA, and Ours.
Emotions: angry, happy, sad, excited (2 sets each).

Task 2 — intensity ladder (α = 0, 0.25, 0.50, 0.75, 1).

Same utterance per emotion: speech, then Ours residual steering, then SA3 lexical blend.
Emotions: angry, happy, sad, excited.
