# SEAM

Listening demo for **SEAM** (speech-conditioned affective music generation).

**Site:** https://jyshin0926.github.io/SEAM/

Task 1 — emotion alignment on IEMOCAP Session 5.

Each set: speech, Ours, SA3 lexical, SA3 VA, SA3 anchor, and an unaligned Ours clip.
Emotions: angry, happy, sad, excited (2 sets each).
